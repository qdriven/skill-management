# 检查源页面

捕获会改变构建的证据：布局、内容、资产与状态。通常一份页面简报就足够。

## 视觉结构

记录 section 顺序、max-width、留白（gutters）、栏比例与 sticky/fixed 图层。测量标题/正文的字体族、字重、字号、行高与字距。先匹配实际字体，再通过调整宽度修复换行。

从移动宽度一直扫到超出桌面设计的宽度，在每个过渡点附近收窄观察；max-width 上限只在更宽的屏幕上显现。记录堆叠顺序、导航/菜单变化、文字重排与不同的裁剪/资产。缩放过的桌面截图不能当移动端参考。

访问过懒加载/reveal section 之后再捕获整页证据，外加全尺寸 hero 与交互视图。字体或入场动效可能让早期截图产生误导。

## 资产

使用可用的浏览器资产清单/下载工具，或基于 DOM 的 URL 直接下载。包括：

- 图片：`currentSrc`、`srcset`、尺寸、`object-fit`、裁剪位置、alt 文本。
- 图层：可见的图片/背景/SVG 及其堆叠/定位方式。
- 视频：来源、poster、autoplay/loop/mute 行为、宽高比、控件。
- 字体：实际加载的字体族/字重，以及页面使用的字体文件。
- SVG：viewBox 以及引用的渐变、遮罩、symbol 与滤镜。

保存克隆范围内使用的资产及其 源 URL → 本地路径 映射。区分重名文件。检查 content type、尺寸与浏览器实际渲染：HTTP 成功也可能返回错误页；CDN 可能在不改 URL 扩展名的情况下变更格式。

公开字体/图片在浏览器 bundle 中下载失败时，直接下载观察到的 URL。未解决的资产保持显式记录，并保留适用的署名。

## 状态证据

记录 触发器 → 可见结果。先滚动再点击，避免把 pinned 场景误判为 tab。检查替代内容、选中态、布局与过渡。

用浏览器支持的 DOM 求值测量重要的前后样式。对页面上观察到的选择器，有用字段包括 textContent、getBoundingClientRect()，以及 computed 的 font、letterSpacing、color、background、gap、padding、borderRadius、position、transform 与 transition。

页面级脚本（平滑滚动、吸附、光标跟随、页面过渡）会改变每一次交互。从根类名、全局样式与已加载脚本识别它们，并记录其 options。

求值环境有差异：只读 DOM 快照可能缺少 `document.fonts` 之类的 API。缺失的测量用资产元数据或开发者检查获得，而不是从不受支持的 API 推断值。
