# 事故笔记：已知失败模式

与浏览器驱动方式无关的克隆事故经验。观察（SKILL 第 3 节）与对比（第 5 节）时对照检查。

## 资产

- **favicon.ico 是硬要求。** 没写 link 标签的站也会响应 `/favicon.ico`；浏览器照样请求，404 噪音照出。一律抓下来自托管。
- **URL 扩展名会撒谎。** `.png` 的 URL 可能返回 AVIF/WebP；核实响应 content-type 与字节，本地存真实格式。
- **HTTP 200 ≠ 资产。** CDN 与图片优化器会用 200 返回错误页/占位图。靠解码验证尺寸，不靠状态码。
- **`/_next/image`（Next.js 优化器）在 origin 参数被拒时返回 HTML 错误壳**——别镜像这类 URL；解析到底层资产直接存。
- **分层视觉是多个资产。** 背景水彩 + 前景 mockup + 覆盖图标是分开堆叠的元素。先检查堆叠关系，再决定合成一张图还是 HTML 重建。
- **动画 SVG 依赖祖先。** 共享 symbol、字体、祖先选择器 keyframes。单导出 SVG 会丢动画；连带依赖一起搬，并观看完整循环。
- **字体：声明 `@font-face` 前核实真实字重/样式。** 静态 medium 文件冒充可变字族会让正文过重。锁定/订阅字体（Typekit）需要从观察到的文件自托管。

## 行为

- **布局之前先定交互模型**：滚动驱动 vs 点击驱动 vs 时间驱动。把滚动驱动的 section 做成点击驱动是另一种产品——最贵的错误。
- **pinned 场景需要滚动距离与释放行为**，不只是 `position: sticky`。量出 pin 时长。
- **"动画视觉"可能是视频。** 重建动效前先查 `<video>`/媒体元素；有真媒体就用真媒体。
- **平滑滚动通常是 Lenis**（`<html>` 上的 `lenis` 类，或 `window.lenis`）。读它的 options；脚本化滚动会绕过它，让对比说谎。
- **整页截图 ≠ 看过的页面。** 不先滚动，reveal 内容不可见。懒加载媒体要滚动后才会进网络日志。
- **拖拽验证需要真实输入。** 合成事件 `isTrusted: false`；验证不了的行为如实记为未验证，不谎报成功。

## 对比

- **在相同视口、滚动位置与状态下对比，且等动画稳定。** 入场动画让两边的早期截图都失真。
- **Console 必须干净。** 运行时错误与资产加载失败是缺陷，页面看起来对也一样。
- **Tailwind 站源：** 直接抽 section 的 cleaned `outerHTML` 往往比手工转抄 class 更忠实。
