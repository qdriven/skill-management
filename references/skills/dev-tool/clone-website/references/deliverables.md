# Deliverables: artifact set and templates

Every clone app (`apps/<slug>/`) carries the same artifact skeleton — created by `init-clone.mjs`, filled by the workflow.

## Layout

```
apps/<slug>/
├── NOTES.md                 # source info, license verdict, prediction, scores (always)
├── docs/
│   ├── RUNSHEET.md          # checkbox + evidence per step (anti-compression contract)
│   ├── research/
│   │   ├── page-brief.md    # section order, typography, measurements, asset map
│   │   ├── BEHAVIORS.md     # trigger → visible result, per interaction
│   │   └── components/<name>.spec.md   # one spec per delegated section (≤150 lines)
│   └── qa/                  # per-iteration comparison screenshots
├── RECON/                   # tool output, keep as evidence
│   ├── original-recon.json / clone-recon.json / *-summary.md
│   ├── screenshots/  routes/  interactions/  network/  sourcemaps/  assets/
│   └── diff.json / diff.png # visual-diff output
├── site/                    # mirror output (mirror path only)
├── CLONE_REPORT.md          # compare-recon output + human notes
└── CLONE_AUDIT.md           # audit-clone output (residue check before handoff)
```

## RUNSHEET.md template

```markdown
# RUNSHEET — <slug>
| # | Step | Done | Evidence (path / command / score) |
|---|------|------|-----------------------------------|
| 1 | init + license verdict | [ ] | |
| 2 | recon original | [ ] | RECON/original-recon.json |
| 3 | classify L? + mode | [ ] | NOTES.md 预判 |
| ... |
```
One row per workflow step, evidence mandatory. Re-read after context compression; do not trust memory of unchecked boxes.

## Component spec template (docs/research/components/<name>.spec.md)

```markdown
# <Section name>
## DOM structure        (nested outline, real class hints)
## Computed styles      (exact values: font, color, bg, gap, padding, radius, transform…)
## States & behaviors   (trigger → before/after values → transition; hover/focus/active/scroll)
## Content              (verbatim text)
## Assets               (source URL → local path, dimensions, crop)
## Breakpoints          (what changes at each width)
```
Split when over ~150 lines. The spec is the single source of truth for the builder; builder questions are answered from the spec, not memory.

## CLONE_REPORT.md

Auto-generated by `compare-recon.mjs`; append a human section: what was verified vs not, remaining gaps, legal note. Never delete the tool's numbers — annotate them.
