# 评估：复杂度、模式、评分

SKILL.md 第 1 节的配套文档。动工前定级，交付后评分。

## 复杂度分级 L1–L6

| 级别 | 信号 | 诚实保真上限 |
|---|---|---|
| L1 | 静态 HTML/CSS | 90–98%（或经镜像 1:1） |
| L2 | CMS/营销站，模板化页面 | 85–95% |
| L3 | React/Next/Vue 内容前端 | 80–95% |
| L4 | 动画品牌站（GSAP/Lenis/视频蒙版） | 50–80%——节奏与视觉语法比像素更重要 |
| L5 | WebGL/Canvas/Three.js 为核心 | 30–95%——完全取决于能否找到真源码/shader |
| L6 | SaaS/电商/登录业务逻辑 | 只做展示层；交易类 mock |

## 四种模式

- **忠实复刻**——原样复现。不走 design-DNA 捷径；真源码/真资产即真相。
- **视觉复刻**——保留观感，后续换内容；可提取 design-DNA（token → CSS 变量）。
- **内容爆改**——保留结构与特效，文案/媒体/品牌从头就换。
- **技术拆解**——目标是书面技术拆解（TEARDOWN.md），不是可运行的副本。

动工前把定级 + 模式 + **复刻前预判**（哪些可高保真、哪些近似、哪些不做、主要风险）写进 `apps/<slug>/NOTES.md`。

## 交付后评分（每维 0–5，必须有证据支撑）

源证据 / 结构保真 / 视觉保真 / 动效交互 / 响应式 / 功能完整 / 内容替换 / 法务部署风险。没有证据（源码行、截图、运行结果）支撑的分数不算分数。记入 NOTES.md；`compare-recon.mjs` 会把量化部分自动算进 CLONE_REPORT.md。
