# Framer 与动效页面

用于 Framer 生成的页面，或超出简单 hover 过渡的动效。Framer 只是发布工具；在目标框架中复现其渲染后的设计与行为。

## Framer 检查

Framer 可能渲染重复的桌面/移动两套 DOM 变体，并用断点类隐藏其中一套。在每个视口读取**可见**的布局/computed styles，而不是复制全部节点。`data-framer-name` 标识 section；生成的类名不代表组件架构。

等待 hydration/入场动画完成，并滚动浏览首屏以下的内容。位置变化重要时，捕获初始位置与 reveal 后位置。只靠整页截图可能让屏幕外的 reveal 内容不可见。

使用 `currentSrc`、按最大渲染尺寸足够的分辨率，以及观察到的裁剪方式。Framer CDN 的图片 URL 即使文件名是 PNG 也可能返回 AVIF。校验字节内容，本地使用真实格式。字体与 SVG 定义是保真度的一部分。

声明 `@font-face` 之前检查每个字体的实际字重/样式；把一个静态 medium 文件当作可变字族使用，会让正文过重。资产打包漏掉公开字体时，直接取其观察到的 URL。导出的内联 SVG 需要带上命名空间与引用定义才能作为独立文件工作；确认它们能通过本地 `<img>` URL 渲染，而不只是内联时可用。

动画 SVG 可能依赖祖先选择器、共享 symbol、字体与样式表关键帧。保留这些资产依赖，并观看完整循环：把重复序列换成几个一起脉动的物体，会丢失源行为。

CMS 网格要访问提供的路由并逐个尝试筛选器。映射各目的地：静态的初始状态列表无法复现筛选/导航行为。

重建语义化的组件/数据。部署脚本与压缩包装只是证据，不是粘贴进新 app 的代码。

## 动效检查

| 驱动 | 证据 | 典型实现 |
|---|---|---|
| 时间 | 循环、暂停、方向、循环播放的媒体 | CSS keyframes、视频、动画库 |
| 滚动 reveal | 入场边界、起止位置、反向回放 | IntersectionObserver + CSS |
| 连续滚动 | 进度、pin 时长、图层速度 | 滚动进度 + CSS 变量或动画库 |
| 点击/hover | 替代内容、过渡、关闭/导航 | React state + CSS |
| 指针/canvas | 响应方式、渲染器/媒体身份 | 匹配的渲染器，或披露的近似实现 |

观察双向与移动端。pinned 场景需要滚动距离与释放行为，而不只是 sticky 定位。动画化的视觉可能本质是视频：有实际媒体就用实际媒体。

匹配可测量的 easing/时长。动画循环随组件生命周期清理。Framer 的平滑滚动是 Lenis：`html` 上的 `lenis` 类或 `window.lenis` 全局变量会暴露可复现的 options。

## 验证体验

在可比位置对比初始、激活与稳定状态。动效过程中测试控件，离开页面再返回以发现卡死状态。确认动效不会撑宽文档或永久隐藏内容。对未实现的 shader/canvas 行为要点名说明，而不是拿一张静帧当证明。
